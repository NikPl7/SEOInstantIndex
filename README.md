# SEO InstantIndex

**by [impik.dev](https://impik.dev)**

WordPress-плагин для мгновенной отправки URL в **IndexNow** (Bing, Yandex, Seznam, Naver) и **Google Indexing API** при публикации и обновлении контента.

---

## Возможности

- 🔵 **IndexNow** — один запрос уведомляет Bing, Yandex, Seznam, Naver одновременно
- 🔴 **Google Indexing API** — прямая отправка в Google через Service Account
- ⚡ **Авто-отправка** — срабатывает при публикации и обновлении записи
- 📋 **Настраиваемые типы контента** — выбирайте какие CPT отслеживать
- 🛠 **Ручная отправка** — вставьте список URL и отправьте вручную
- 📦 **Массовая отправка** — все опубликованные страницы сайта за раз (батчами по 100)
- 📊 **Лог** — каждая отправка с HTTP-кодом, статусом и ошибкой
- 🔑 **Автогенерация ключа IndexNow** — плагин сам создаёт ключ и файл верификации

---

## Установка

1. Скопируйте папку `seo-instantindex` в `/wp-content/plugins/`
2. Активируйте плагин в **Плагины → Установленные**
3. Перейдите в **Инструменты → SEO InstantIndex**

---

## Настройка IndexNow

### Автоматически (рекомендуется)

1. **Инструменты → SEO InstantIndex → Настройки**
2. Нажмите **«✨ Создать ключ автоматически»**
3. Плагин сгенерирует ключ, создаст файл верификации в корне сайта и проверит HTTP-доступность

### Вручную

1. Сгенерируйте ключ на [indexnow.org](https://www.indexnow.org/documentation)
2. Создайте файл `<ваш-ключ>.txt` в корне сайта, содержащий только этот ключ
3. Введите ключ и URL файла в настройках плагина

---

## Настройка Google Indexing API

Google разрешает этот API для страниц вакансий с `JobPosting` и видеотрансляций с `BroadcastEvent` внутри `VideoObject`. Для обычных статей и страниц он не является универсальным способом индексации. Отправка URL не гарантирует попадания в поиск. [Ограничения Google](https://developers.google.com/search/apis/indexing-api/v3/quickstart).

1. Откройте [Google Cloud Console](https://console.cloud.google.com/)
2. Создайте проект → включите **Indexing API**
3. Перейдите в **IAM → Сервисные аккаунты** → создайте аккаунт
4. Создайте ключ в формате **JSON** и скачайте файл
5. Добавьте email сервисного аккаунта как **Владельца** в [Google Search Console](https://search.google.com/search-console)
6. Вставьте содержимое JSON-файла в поле **Service Account JSON** в настройках плагина

## Типы контента

По умолчанию авто-отправка включена для:

| Тип | Slug |
|-----|------|
| Записи | `post` |
| Страницы | `page` |

Снимите галочку с любого типа в настройках, чтобы исключить его из авто-отправки.

---

## Лог

Вкладка **Лог** показывает последние 300 отправок:

| Колонка | Описание |
|---------|----------|
| Время | Дата и время отправки (серверное) |
| Тип | `auto` / `manual` / `bulk` |
| IndexNow | HTTP-код ответа, ✅/❌ |
| Google | Количество принятых URL, ✅/❌ |
| URL | Первые 3 URL из батча |

---

## HTTP-коды IndexNow

| Код | Значение |
|-----|----------|
| 200 | OK — URL принят |
| 202 | Accepted — URL поставлен в очередь |
| 400 | Bad Request — неверный формат запроса |
| 403 | Forbidden — ключ не совпадает с файлом |
| 422 | Unprocessable — URL не принадлежит хосту |
| 429 | Too Many Requests — превышен лимит |
