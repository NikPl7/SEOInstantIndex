# SEO InstantIndex

Плагин [impik.dev](https://impik.dev) для уведомлений поисковых систем о новых и обновлённых страницах WordPress. Результаты запросов видны в журнале. Решение об индексации принимает поисковая система.

## Установка

1. Поместите папку `seo-instantindex` в `wp-content/plugins/` и активируйте плагин.
2. Откройте «Инструменты → SEO InstantIndex».
3. Подключите нужные сервисы и выберите типы записей для автоотправки.

Нужны WordPress 5.6 или новее и PHP 7.4 или новее. Для Google требуется расширение PHP OpenSSL.

## IndexNow

Нажмите «Создать ключ». Плагин создаст текстовый файл в корне сайта и сохранит ключ после проверки файла. Если сервер запрещает запись в корень, создайте файл вручную. Впишите ключ и полный адрес файла на домене сайта, сохраните настройки и нажмите «Проверить файл».

По умолчанию IndexNow получает уведомления о записях и страницах. Список типов можно изменить в настройках.

## Google Indexing API

Google разрешает этот API для вакансий с разметкой `JobPosting` и видеотрансляций с `BroadcastEvent` внутри `VideoObject`. [Требования Google](https://developers.google.com/search/apis/indexing-api/v3/quickstart)

Включите Indexing API в Google Cloud, создайте сервисный аккаунт с ключом JSON и добавьте этот аккаунт как владельца ресурса в Search Console. Вставьте JSON в настройки плагина. Пустое поле сохраняет прежний ключ. Для удаления отметьте «Удалить сохранённый ключ» и сохраните настройки.

Автоотправка в Google включается отдельно. Выбирайте только типы записей, где весь контент соответствует требованиям Google. При обновлении с 1.2.1 сохранённый аккаунт остаётся, а список типов Google изначально пуст.

## Отправка и журнал

- При публикации или обновлении записи выбранного типа плагин ставит её URL в очередь. Приватные и защищённые паролем записи пропускаются.
- Во вкладке «Отправка» можно добавить до 1 000 URL текущего сайта, по одному на строку. Для отправки этого списка в Google отметьте отдельную галочку.
- Массовая отправка обрабатывает опубликованные записи выбранных типов порциями. У каждого сервиса свой список типов. IndexNow получает до 100 URL за запрос, Google получает отдельный запрос на каждый URL.
- Очередь работает через WP-Cron. На сайтах с отключённым встроенным запуском очередь обрабатывает настроенный на сервере cron. При временной ошибке плагин делает до двух повторных попыток.
- Журнал хранит до 300 последних результатов. В нём виден итог по каждому сервису после завершения отправки или всех повторных попыток. IndexNow `202` означает, что ключ ещё проверяется.

## Оформление в теме сайта

У плагина есть собственное оформление. Тема может изменить акцент кнопок, скругление карточек и шрифт фильтром `hcin_admin_design_tokens`. Он действует только на экране SEO InstantIndex. Шрифты должны быть доступны браузеру, фильтр сам их не загружает.

```php
add_filter( 'hcin_admin_design_tokens', static function ( array $tokens ): array {
    return array_merge( $tokens, [
        'accent'      => '#2458A6',
        'radius'      => 14,
        'font_family' => 'system-ui, sans-serif',
    ] );
} );
```

## Проверка

`php tests/settings.php` проверяет настройки, сохранение ключа Google, независимые списки типов и целостность закодированных URL без загрузки WordPress и без сетевых запросов.
